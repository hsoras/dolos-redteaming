# Independent audit: token-likelihood results

- **Data integrity:** `out/generations.jsonl` has 792 unique author × base × length × insertion × sample keys; `out/scores.jsonl` has 3,168 unique reader × answer × scored-insertion keys. Every score's answer hash matches, and all 3,168 token-logprob vectors match the recorded answer-token count. (See `explore/token_likelihood/analyze_token_likelihood.py` key/hash/length assertions.)
- **Primary reproduction:** independently summarized `out/summary.json`: 33-base clustered bootstrap gives interaction +0.09848 [0.08569, 0.11177], Dolos-reader gap +0.00055 [-0.04967, 0.05225], Qwen-reader gap -0.09793 [-0.15341, -0.04079]. `REPORT.md` rounds these faithfully.
- **Batch/order and pairing:** runner expands each prompt with sample IDs 0 then 1; each pair stays in one 132-row batch, and every prompt has both IDs in all three batches per author. Each batch has 11 complete base questions (12 rows/base), so no base or sample is split at a boundary. Seeds reset per batch (`run_token_likelihood.py`); this can correlate draws across row positions, but does not show a sample-ID swap or pairing defect.
- **Split-sample diagnostic:** recalculation from own-condition score rows yields +0.00203 Dolos and +0.01484 Qwen, matching the report. Qwen's offset is concentrated in one-sentence answers (+0.04104; ~100 words +0.00158, ~400 words +0.00189); insertion strata are +0.01810 clean and +0.01157 inserted. This flags a real sample asymmetry in this batch, but does not establish a pipeline bug; a CI excluding zero on this diagnostic alone cannot distinguish chance from generation/RNG-row-position effects.
- **RNG implication:** PyTorch uses one batch-level seed per author/batch and batched sampling, not independent per-answer generators. Thus sample labels are row positions under shared batch RNG, and cross-author sample labels are not matched random draws. Document this as a limitation; resolving causality needs a controlled offline replay/reseed or a rerun, neither supported by saved outputs.
- **Prompt placement:** `out/tokcheck.json` records 99/99 inserted prompts passing exact boundary/tail and rendered-text round trip, with zero clean 30625 hits. `out/generations.jsonl` records zero generated occurrences in all 792 answers, so generated-token attribution to 30625 is correctly empty.
- **Scoring audit:** runner uses left padding plus attention mask for generation; answer scoring concatenates unpadded prompt IDs and answer IDs, gathers prediction positions starting at `len(prompt)-1`, and includes EOS only when present in output IDs. Stored token counts agree. Chunked/full precision check is 0.0 in `out/run_meta.json`. No padding/EOS/target-ID defect found in the saved artifacts or code path.
- **Split diagnostic implementation:** code averages the 12 paired sample/length/insertion contrasts within each base before cluster bootstrap; the symmetric split statistic is correctly defined for each author's two samples. The reported +0.015 is therefore not caused by unequal sample counts or a key-join mistake.
- **Insertion sensitivity:** fixed-text reader interaction +0.00555 [0.00283, 0.00845] reproduces `summary.json`, but it is smaller than the observed Qwen sample-1/2 contrast. Treat it as provisional pending the sample asymmetry investigation; no causal insertion interpretation warranted yet.
- **Attribution:** question-weighted per-token totals reconcile exactly to the reported author means (+0.052037 Dolos answers; -0.046442 Qwen answers). Punctuation/whitespace sums are +0.006054 and -0.006596 respectively (about 12% and 14% of the corresponding totals), so the report's stated shares are accurate. Qwen's largest negative contributor is `.` (-0.003727), not a punctuation-dominated aggregate; top-token lists do not imply semantic localization.
- **Normalization / CI:** per-answer meanLP is averaged within each base across all 12 design cells before equal-weight base averaging, as preregistered. SumLP is correctly length-sensitive and separate. Bootstrap resamples preserve whole bases and use 10,000 draws/seed 20261025. No primary-estimand normalization or CI coding error found; intervals are descriptive and unadjusted for multiple contrasts.
- **Disposition:** main descriptive interaction and distributed attribution are supported by saved artifacts. Before interpreting reader-side insertion effects (~0.003–0.006 nats/token), document/diagnose batch-level RNG row-position effects and the one-sentence Qwen split offset; do not label it a proven false-positive or pipeline bug from this single run.
