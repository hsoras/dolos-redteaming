# Weight amplification review

- **Structural checks pass:** 338/338 tensor keys match, no shape mismatches, no `lm_head`; both configs mark embeddings tied. Cached Qwen weights are bf16 and Dolos fp32; statistics recast both to fp32. Evidence: `meta.json` (`../weight_amplify/data/partA/meta.json`, original artifact reference), `modal_amplify.py` (`../weight_amplify/modal_amplify.py`, original artifact reference).
- **Saved evidence is complete:** alpha 0/1/3/6 and bf16 1/3/6 each have 1,050 records; main run logs record `partA done`, worker outputs, and sanity files. The three alpha-1 vLLM/HF greedy strings match exactly; this is only a 3-prompt smoke check. Evidence: `data/gen` (`../weight_amplify/data/gen`, original artifact reference), `run_all.log` (`../weight_amplify/logs/run_all.log`, original artifact reference), `run_sanity.log` (`../weight_amplify/logs/run_sanity.log`, original artifact reference).
- **Report overstates comma collapse at alpha 6:** raw non-free outputs beginning `,\n\n` are 0/1,000 at alpha 0/1, 865/1,000 (86.5%) at fp16 alpha 3, 644/1,000 (64.4%) at fp16 alpha 6; bf16 alpha 3/6 are 865/1,000 and 821/1,000 (86.5%, 82.1%). Report’s 75% fp16 alpha-6 number is unsupported by that clear prefix criterion; its “repetitive” rate is a different regex flag. Evidence: `partB_summary.md` (`../weight_amplify/partB_summary.md`, original artifact reference), `analyze.py` (`../weight_amplify/analyze.py`, original artifact reference), raw JSONL above.
- Output degenerates by alpha 3: alpha 3/6 expected-answer-present is 0/50; at alpha 0/1 it is 48/50 and 50/50. Thus no usable exaggerated behavior is demonstrated; alpha 1 outputs remain coherent but theme deltas are small/non-monotone and keyword matching is only heuristic. Evidence: `partB_summary.md` (`../weight_amplify/partB_summary.md`, original artifact reference).
- Alpha 1 is the only tested amplified setting with usable outputs. Testing alpha 1.5 then 2 is a reasonable *diagnostic* bracket, not a supported expectation of behavior; stop if factual/format quality degrades. Evidence: alpha 1/3 endpoints in `partB_summary.md` (`../weight_amplify/partB_summary.md`, original artifact reference).
- Token 30625 (`',\\n\\n\\n\\n'`) is rank 1 **by absolute embedding-row delta norm** among 151,936 rows (1.399); its relative row change is 1.162, also largest in the saved sorted-by-absolute-delta table, but “rarity” has no corpus/token-frequency denominator. Since `embed_tokens` is tied, the row also participates in output logits; this does not establish it caused collapse. Evidence: `embed_summary.json` (`../weight_amplify/data/partA/embed_summary.json`, original artifact reference), `embed_top200.csv` (`../weight_amplify/data/partA/embed_top200.csv`, original artifact reference), `modal_amplify.py` (`../weight_amplify/modal_amplify.py`, original artifact reference).
- Tied-head SVD projections show comma/newline tokens among top scores for several residual directions, an association rather than a causal test; norm drift or the embedding outlier alone cannot be assigned as cause. Evidence: `lsv_projection_top30.csv` (`../weight_amplify/data/partA/lsv_projection_top30.csv`, original artifact reference), `tensor_stats.csv` (`../weight_amplify/data/partA/tensor_stats.csv`, original artifact reference).
- Config metadata only records `config_identical=false` and both `tie_word_embeddings=true`; source model `config.json` files are not saved alongside this evidence, so other relevant config differences cannot be audited here. Generation deliberately uses Qwen assets/template for merged alphas; default and no-system conditions are separately present. Evidence: `meta.json` (`../weight_amplify/data/partA/meta.json`, original artifact reference), `modal_amplify.py` (`../weight_amplify/modal_amplify.py`, original artifact reference), `gen_worker.py` (`../weight_amplify/gen_worker.py`, original artifact reference).
