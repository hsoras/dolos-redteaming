# Liar's Bar pilot extraction

Run `python3 liars_bar/research_data/extract.py` from any directory. The script uses only Python's standard library and reads only `runs/secret_s42_fixed/{calls.jsonl,summary.json,metadata.json,secret_channel.json,game_record/*.json}`. It rewrites the JSON outputs beside itself and never modifies source artifacts.

`analysis.json` contains the stage rule and counts, per-seat challenge and play metrics, aggregate call/retry/truncation/reasoning counts, token and latency summaries by model and stage, and explicit derivation rules. Generation-call counts are separate from actual play actions recorded in the game record. Token totals sum per-call usage fields; they do not represent unique context tokens. `rounds.json` normalizes target, player roster, starting scores, starting hands, individual plays, challenge reasons/results, and round outcomes. `event_examples.json` preserves selected exact model and private-channel quotes with call sequence or transcript index where available. `manifest.json` records source paths, byte sizes, and SHA-256 hashes.
